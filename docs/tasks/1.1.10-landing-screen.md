# Task 1.1.10 – Landing screen (empty state, totals) and tab bar shell

## Goal

After login the user lands on My devices: a greeting, the three totals and, with no devices yet, a "No devices yet" card with an Add device button. A bottom tab bar (Devices, History, Alerts, Profile) frames the logged-in screens.

## Requirements covered

- 3.1 On first login there are no devices: show an empty screen with an "Add device" button.
- 3.3 Show totals: devices, connected, open alerts (Devices is a real count; see below).
- Config `features.history` / `features.alerts`: their tabs are hidden when off.

## Scope

**In scope**

- `HomeScreen` from `docs/screens/05_home_empty.png` (mockup lines 187–221).
- `DeviceService` (watch the user's devices) with `LocalDeviceService` over the existing `DevicesDao`.
- `AppShell`: bottom tab bar (mockup lines 788–797) with go_router `StatefulShellRoute`.
- Placeholders: History, Alerts, Profile (holds the temporary Log out until 1.1.11) and `/add` (Add device, task 1.2.7).

**Out of scope (waiting on Module 2 and the alerts module)**

- 3.2 Device cards (name, quick reading, connection, battery, Seen): need connection state (`feature/p1-m2-ble-transport`), readings and device profiles (`module/p1-m2-add-device`).
- 3.4 Battery colours, 3.5 swipe to delete, 3.6 reorder.
- Real Connected and Alerts counts: shown as 0 until connection state and stored alerts exist.

## Details

- Greeting: "Good morning," before 12:00, "Good afternoon," before 17:00, otherwise "Good evening,"; then the user's first name.
- Totals: each card is read as one phrase ("0 Devices"); the labels mean colour is never the only signal.
- The empty card shows only when the user has 0 devices; with devices it is hidden and the list area is left for Module 2's cards.
- Tab bar: accent for the selected tab, muted for the others; tapping the current tab returns to its first screen. History and Alerts tabs are hidden, and their routes go to `/home`, when their feature is off.
- Log out moved from the old home placeholder to the Profile placeholder (still asks "Log out?" first).
