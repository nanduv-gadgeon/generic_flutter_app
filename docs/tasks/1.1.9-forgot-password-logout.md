# Task 1.1.9 – Forgot password (device verification) and log out

## Goal

A user who forgot their password can set a new one after confirming with the phone's own screen lock, and a logged-in user can log out after confirming.

## Requirements covered

- 2.3 Forgot password. Phase 1: the user confirms with the phone's Face ID, fingerprint or passcode, then sets a new password. Phase 2: the cloud emails a reset link (hook only).
- 2.4 / 9.7 Log out ends the session on the phone.
- 2.5 Each account action shows a loading spinner with no text.

## How the reset works

One form: email, new password, confirm password (rules from `AuthValidators`). **Reset password** then runs, in order:

| Step | If it fails | Message |
| --- | --- | --- |
| 1. `canVerifyOwner()`: any PIN, pattern, passcode or biometric set up | `NoScreenLock` | Set up a screen lock (PIN, pattern, Face ID or fingerprint) on this phone to reset your password. |
| 2. `authenticate()`: the phone's own prompt | `OwnerNotVerified` | We couldn't confirm it's you. Try again. |
| 3. Look up the email (only after step 2, so emails can't be probed without unlocking) | `NoAccountForEmail` | No account with this email on this phone. |
| 4. Hash and save the new password | – | Back to login: "Password changed. Log in with your new password." |

The user is not logged in by a reset. A Face ID login they turned on stays on.

`canVerifyOwner` is separate from `isAvailable` because `isAvailable` needs an enrolled face or fingerprint; a phone with only a PIN must still be able to reset.

## Android vs iPhone

The logic is the same on both (behind `BiometricAuth`); only the system prompt differs.

| | Android | iPhone |
| --- | --- | --- |
| Prompt | Fingerprint / face sheet | Face ID / Touch ID |
| Fallback | "Use PIN/pattern" in the sheet | "Enter Passcode" after a failed try |
| Permission | None | Once, text from `NSFaceIDUsageDescription` ("Confirm it's you with Face ID") |
| No screen lock | `isDeviceSupported()` false → message | Same |

## iPhone manual check (needs a Mac with Xcode, iOS Simulator)

1. Features → Face ID → Enrolled. Forgot password → Reset → Features → Face ID → Matching Face → back on login with the message; log in with the new password.
2. Same, but Non-matching Face → "Enter Passcode" offered; cancel → "We couldn't confirm it's you."
3. Simulator with no passcode set → screen-lock message.
4. First Face ID use shows the permission text "Confirm it's you with Face ID".
