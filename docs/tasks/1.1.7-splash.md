# Task 1.1.7 – Splash screen (logo + spinner) reading the config file

## Goal

The app opens on the customer's branded splash screen (logo, app name and spinner) while it reads the config file, opens the local database and checks the backend, then goes to login.

## Requirements covered

- 1.1 The splash screen shows the logo and a loading spinner.
- 1.2 While it shows, the app reads the config file (loading itself was built in 1.1.4).

## Scope

**In scope**

- The splash design from `docs/screens/01_splash.png`: config primary background, `brand.logoSplash` (96 px), app name, white spinner.
- A neutral first frame (plain spinner) until the config has loaded, since there is no brand to show yet.
- An initials tile if the logo file is missing.

**Out of scope**

- Config loading, schema check, start-up errors and Retry (1.1.4, unchanged).
- Native launch screens and app icons (per customer flavor, later).
- Any change to `app_config.json` or the schema.

## Interfaces / files expected

| File | Layer | Purpose |
| --- | --- | --- |
| `lib/presentation/splash/splash_screen.dart` | presentation | Neutral first frame, then the branded splash |
| `lib/presentation/widgets/brand_header.dart` | presentation | `BrandHeader.splash`: splash logo and white name on the primary colour |

## Phase behaviour

| isCloud | Behaviour |
| --- | --- |
| false (Phase 1) | Branded splash while the database opens; no network calls. |
| true (Phase 2) | Same; while the backend check runs. If it fails, Retry shows on the plain background, and pressing it shows the branded splash again. |

## Acceptance criteria

- [x] Neutral spinner before the config loads, then the branded splash matching `01_splash.png`
- [x] Logo from `brand.logoSplash`, with an initials fallback; background colour from the config
- [x] Start-up errors and Retry show on the plain background, unchanged
- [x] Login screen header unchanged
- [x] Unit tests added (mocktail); `flutter analyze` and `flutter test` are clean
- [x] The spinner has the Semantics label "Loading"; the brand name is announced as a header
